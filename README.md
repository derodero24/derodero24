## About

- 🦀 I write **Rust-powered npm packages** that ship native Node.js bindings plus a WebAssembly build, so the same API works in Node.js, Deno, Bun, browsers and edge runtimes.
- 🧩 I like **strict types and small APIs**: zero runtime dependencies, typed errors and safe defaults.
- 🌐 My background is in **full-stack web**, **Web3** and **ML/RL**. Many of my older repos are experiments from those years.
- 📝 I write technical articles on [Qiita](https://qiita.com/derodero24).
